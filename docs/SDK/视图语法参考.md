# 视图语法参考

本页是 `view!` 的封闭词表：intrinsic 标签、控制标签、属性、事件与组件 props。未登记的名称在宏展开期报错，不会静默生成未知节点。class token 与 `style:*` 的类型规则见 [样式与输入](样式与输入.md)，组件的挂载与数据语义见 [界面与组件](界面与组件.md)。

## 标签

| 标签 | 子节点 | 用途 |
| --- | --- | --- |
| `view` | 任意 | 通用容器；布局、背景、边框与 `role` 都落在它上面 |
| `form` | 任意 | 表单容器；聚焦输入按 Enter 时向最近的 `form` 派发 `on:submit` |
| `text` | 字符串或表达式 | 文本容器；文本整形、换行与 caret 几何来自它的内容 |
| `button` | 文本 | 按钮；指针点击与键盘激活派发 `on:click` |
| `checkbox` | 无 | 复选框叶子；`checked` 同步布尔状态，切换派发 `on:change(bool)` |
| `text-input` | 无 | 单行编辑器叶子；`value` 是字符串，本地编辑派发 `on:input(String)` |
| `Show` | 任意 | 条件分支；`when` 为真时渲染子节点，否则渲染 `fallback` |
| `For` | 行 factory | 列表；`each` 提供行集，`key` 提供稳定身份，`store` 提供行数据来源 |
| PascalCase | 任意 | Rust 组件；props 按函数参数名传递 |

`checkbox` 与 `text-input` 是叶子，带子节点会在场景构建时报错。`view` 与 `form` 都是容器，`form` 另外参与 Enter 提交。

## 属性

| 属性 | 值类型 | 适用 | 说明 |
| --- | --- | --- | --- |
| `class` | 字符串字面量 | 所有标签 | 闭集 utility 词表；条件变体见 [样式与输入](样式与输入.md) |
| `style:background` | `Color` | 所有标签 | 填充色 |
| `style:color` | `Color` | 文本内容 | 文本色；由绘制文本的元素使用 |
| `style:border-color` | `Color` | 所有标签 | 边框色 |
| `style:opacity` | `Opacity` | 所有标签 | 只作用于该元素自身的绘制 |
| `style:width` | `Length` | 所有标签 | `px()` 是逻辑点，`em()` 按元素字号 |
| `style:height` | `Length` | 所有标签 | 窗口化 `For` 的行槽高度来源 |
| `role` | 字符串 | 容器 | 语义角色；`main`、`list`、`listitem`、`group`、`toolbar` 等影响辅助技术分组与列表语义 |
| `aria:label` | 字符串 | 所有标签 | 辅助技术名称；控件没有可见标签时使用 |
| `aria:pressed` | `bool` | `button` | 语义选中状态，与 `aria-pressed:` 条件一致 |
| `disabled` | `bool` | 控件 | 禁用输入、焦点与事件派发 |
| `value` | `String` | `text-input` | 受控文本值 |
| `checked` | `bool` | `checkbox` | 勾选状态 |
| `type` | 字符串 | 所有标签 | 仅 `button` 的 `type="submit"` 改变行为：点击提交最近的祖先 `form` 恰好一次；其它值保留为呈现属性 |
| `id` | 字符串 | 所有标签 | 保留的呈现属性；Node 身份仍由运行时分配 |
| `when` | `bool` | `Show` | 分支条件 |
| `fallback` | 返回 `view!` 的闭包 | `Show` | `when` 为假时的内容 |
| `each` | `Rows` 投影、行集读源或 `ForSource` | `For` | 行集来源；裸 `RowSet`/`Memo<RowSet>` 必须同时给 `store` |
| `key` | `Fn(&R) -> K` | `For` | 稳定身份；同 key 保留控件与本地状态 |
| `store` | 行 Store | `For` | 行数据与业务键来源；与裸 `each` 行集配合 |
| `row-height` | `Length` | `For` | 窗口化列表的行槽高度；需要随文本缩放时用 `em()` |

字符串属性可以写字面量（`role="main"`），也可以写表达式（`aria:label={label}`）。`class` 只接受字面量，动态 class 不是编译期 token。

`button`、`checkbox` 与 `text-input` 天生可聚焦；任意元素注册 `on:focus` 或 `on:blur` 处理器后也进入焦点顺序。只有 `on:click` 不会让普通容器变为可聚焦。`disabled` 同时阻止输入、焦点与事件派发。`type="submit"` 的按钮只提交一次；文本输入中的 Enter 也提交最近的 `form` 一次，`SubmitEvent` 的 `consume` 或 `prevent_default` 跳过提交默认。

## 事件

| 属性 | 回调 payload | 典型元素 |
| --- | --- | --- |
| `on:click` | `&mut ClickEvent`；零参数闭包也可用 | `button` 或任意可点击容器 |
| `on:click_capture` / `on:click_bubble` | `&mut ClickEvent` | 祖先观察者 |
| `on:dblclick` | `&mut ClickEvent`；`click_count()` 为 2 | 任意元素 |
| `on:input` | `&mut InputEvent`；兼容旧式 `String` | `text-input` |
| `on:change` | `&mut ChangeEvent`；兼容旧式 `bool` | `checkbox` |
| `on:submit` | `&mut SubmitEvent` | `form` |
| `on:keydown` / `on:keydown_capture` / `on:keydown_bubble` | `&mut KeyEvent` | 任意可聚焦元素 |
| `on:focus` / `on:blur` | `&mut FocusEvent` / `&mut BlurEvent`；兼容按值 | 任意可聚焦元素 |
| `on:compositionstart` 等四个阶段 | `&mut CompositionEvent`；兼容按值 | `text-input` |

事件名在展开期校验；未登记的事件是编译错误。`on:input` 只在编辑发生时派发，caret 与 selection 移动不派发。处理器可以返回 `()`、`Result<(), E>`、`WriteOp<T>` 或 `HandlerOutcome`：`Err` 与 panic 停止本事件剩余阶段与默认动作，已提交写入保留，并作为 `HandlerFailed`/`HandlerPanicked` 进入 turn 的 `TurnReport.errors`。`ClickEvent`、`ChangeEvent`、`KeyEvent` 等的 `consume()` 停止后续捕获/冒泡阶段与默认动作，`prevent_default()` 只跳过默认动作；click 路由固定为 root→hit 捕获、最近处理器、hit-parent→root 冒泡。

## 组件 props

PascalCase 标签调用同名的 `#[component]` 函数。属性名对应函数参数，值是参数声明类型的表达式；没有对应参数的属性是编译错误。

```rust
<FilterButton current={filter} value={Filter::Active} label="Active" />
```

`children` 与具名 slot 作为特殊 props 传递，见 [界面与组件](界面与组件.md#children-与具名-slot)。

## 文本子节点

- `"literal"` 生成静态文本；
- `{expression}` 在当前挂载求值一次；表达式返回 `String`、`&str` 或视图文本节点；
- `{move || view! { ... }}` 是 factory，只在接受 factory 的 slot 或 `For` 行位使用；`For` 行 factory 的参数是 `RowView<R>`；
- 结构分支使用 `Show`，不要用 `{if ...}` 代替它。

## 参考页的边界

本页覆盖 `view!` 当前登记的标签、属性、事件与 props 形状；各 intrinsic 的绘制默认值、布局与辅助技术行为由 [界面与组件](界面与组件.md) 与 [渲染场景](渲染场景.md) 描述。Rust 表达式内部仍由编辑器与 `rust-analyzer` 补全；`view!` 的标签与属性补全目前没有语言服务器钩子，见 [#313](https://github.com/ZenUIOrg/zenui/issues/313)。
