# 渲染场景

`zenui-render` 是平台无关的场景 seam：输入 presentation snapshot 与 viewport，输出绝对逻辑几何、文本 run、命中测试和本地编辑装饰。它不依赖 GPU、Win32，也不读取运行时内部。

## 输入与输出

- `Viewport` 携带逻辑宽高与 Window scale。布局始终使用逻辑像素；scale 只随场景交给 surface 后端，不改变几何。
- `Scene::build` 每次做一次完整 Taffy 重排，Node ID 原样保留。场景不是第二棵保留树。
- `Scene::elements()` 按绘制顺序（先序）列出已提交元素；`Scene::node(id)` 按 Node ID 查找。
- `Scene::hit_test(point)` 从最高层向下命中，使用半开区间，返回最上层的 Node ID。
- 每个元素的 `rect()` 是绝对逻辑矩形；文本 run 携带字体、字号、normalized coords、baseline 与绝对 glyph 位置。
- `Scene::decorations()` 给出 caret、selection 与 preedit underline；`Scene::caret(id)` 直接取某个文本输入的光标矩形。

## 内建视觉

场景只理解以下 intrinsic；其他 tag 返回 `UnsupportedTag`：

| tag | 视觉与布局 |
| --- | --- |
| `view` | 容器；默认纵向，`role="main"` 增加 16 内边距，`role="group"` / `"toolbar"` / `"listitem"` 改为横向 |
| `form` | 横向容器，行间距 8 |
| `text` | 文本容器；内容来自直接文本子节点 |
| `button` | 横向居中、内边距、最小高度 24；`aria:pressed` 进入 `Visual::Button` |
| `checkbox` | 16×16 方块；`checked` 进入 `Visual::Checkbox` |
| `text-input` | 带边框和内边距的输入盒，最小 80×24，在行内可伸展 |

正文使用系统 sans-serif、字号 14、行高 1.35。Parley 负责 Latin 与 CJK 的整形与字体回退；场景只做 shaping，glifo/vello 的栅格化留在 GPU 阶段，使用 `TextRun` 携带的字体与 glyph 数据。根元素至少与 viewport 的逻辑高度一致，因此纯高度变化也会重排。

## 属性与本地编辑状态

`value`、`checked`、`disabled`、`aria:pressed`、`role` 参与几何或视觉；`aria:label`、`type`、`id` 是接受的语义属性，不改变几何与绘制。其他属性——包括 `class`、`style:*` 与尚未实现的 `placeholder`——返回 `UnsupportedAttribute`，不会被静默丢弃。

文本输入按 `value` 绘制；组合期间按 `TextEditState::composition` 给出的区间用 preedit 替换该段文本。caret 与 selection 的字符偏移先换算成 UTF-8 字节，再由 Parley 给出几何。折叠的 selection 不产生高亮；preedit 在自己的范围下方画 1 逻辑像素下划线。caret 几何始终来自本地编辑状态，是否绘制由后端结合 `SceneElement::focused` 决定。

## 明确错误

`SceneError` 区分：

- `InvalidViewport`：非有限或负尺寸，或非正 scale；
- `UnsupportedTag`：没有内建视觉的元素；
- `UnsupportedAttribute`：场景 seam 不理解的属性；
- `UnsupportedContent`：`checkbox` 或 `text-input` 带有子节点；
- `BareRootText`：顶层裸文本没有 Node ID，不能成为场景元素；
- `Layout`：Taffy 无法完成布局。

场景构建不 panic，也不忽略未知输入。
