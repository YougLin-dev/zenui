# #203 剪贴板可见证据

日期: 2026-11-25
基线: main ac58dcd（#201 复制/粘贴、#202 剪切）
示例: crates/windows/examples/todo_host.rs（ZenUI Todo / ZenUI Details），debug 构建
外部程序: Notepad 11.2609.11.0，RichEditD2DPT 文档区

## 环境与采集

- 单屏 2560×1600。150% 是当前 144 DPI；100% 从 150% 临时切到 96 DPI，采集后恢复到 144 DPI。
- 100%：主窗口 916×739 物理像素，客户区 900×700；详情窗口 536×459。
- 150%：主窗口 1372×1106 物理像素，客户区 1350×1050；详情窗口 802×686。
- ZenUI 窗口图来自 PrintWindow(PW_RENDERFULLCONTENT)，整窗读取；详情窗口单独成图。
- Notepad 文档图来自 CopyFromScreen，只取活动标签页文档区的屏幕矩形；不截标签栏，
  不读取或修改 Notepad 恢复的其它标签页。Notepad 在采集结束时保持打开。
- 键盘与鼠标由仓库外的 PowerShell 脚本用 keybd_event / mouse_event 注入；每次输入前
  用 SetForegroundWindow 置前并确认 fg 与目标 HWND 相同。
- 文本与选区来自仓库外的 UIA TextPattern 客户端；Notepad 活动标签页同样由
  TextPattern 读取，偏移是 UTF-16 单元。
- 空剪贴板由 OpenClipboard/EmptyClipboard 清空；非文本剪贴板由 Windows.Forms
  Clipboard.SetImage 写入 16×16 位图，两种状态都没有 CF_UNICODETEXT。

## 边界

- 只在单屏 2560×1600 运行；100% 临时切换后恢复 150%，不声明混合 DPI 或多显示器。
- 组合 no-op 只在 150% 采集；100% 覆盖复制、剪切、粘贴、空/非文本与跨窗口。
- 可见互操作只覆盖 Notepad；其它应用与富文本/HTML/图片粘贴不在本切片。
- Notepad 恢复的其它标签页含本地文件；本目录截图不含其标题或内容，采集未修改它们。
  证据文本仍留在系统剪贴板，Notepad 临时标签页未保存。
