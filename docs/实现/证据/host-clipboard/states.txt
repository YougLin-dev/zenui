# #201 剪贴板可见证据

日期: 2026-11-24
基线: feat/201-clipboard-copy-paste
示例: crates/windows/examples/todo_host.rs（ZenUI Todo），debug 构建
外部程序: Notepad 11.2609.11.0，RichEditD2DPT 文档区

## 环境与采集

- 单屏 2560×1600，150%（144 DPI）。
- ZenUI Todo 外框 1372×1106 物理像素，位于屏幕 (48,48)，客户区 1350×1050。
- ZenUI 窗口图来自 PrintWindow(PW_RENDERFULLCONTENT)，整窗读取。
- Notepad 文档图来自 CopyFromScreen，只取活动标签页文档区的屏幕矩形；不截标签栏，
  不读取或修改 Notepad 恢复的其它标签页。Notepad 在采集结束时保持打开。
- 键盘与鼠标由仓库外的 PowerShell 脚本用 keybd_event / mouse_event 注入；每次输入前
  用 SetForegroundWindow 置前并确认 fg 与目标 HWND 相同。
- 文本与选区来自仓库外的 UIA TextPattern 客户端；Notepad 活动标签页的文本同样由
  TextPattern 读取。Notepad 的 UIA 偏移是 UTF-16 单元。

## 应用复制 -> Notepad 粘贴

| 步骤 | 读数 | 证据 |
| --- | --- | --- |
| 草稿键入 `ZenUI clipboard`，Ctrl+A | text=[ZenUI clipboard]，selected=[ZenUI clipboard] | 无（复制前值由 UIA 记录） |
| Ctrl+C | 草稿不变，无 `on:input` | 无 |
| Notepad Ctrl+V | text=[ZenUI clipboard]，15 码元，`90,101,110,85,73,32,99,108,105,112,98,111,97,114,100` | `150-notepad-from-zenui.png` |

## Notepad 复制 -> 应用粘贴

| 步骤 | 读数 | 证据 |
| --- | --- | --- |
| 外部系统剪贴板写入后，Notepad Ctrl+V | text=[Notepad to ZenUI 你好 🙂]，22 码元，`78,111,116,101,112,97,100,32,116,111,32,90,101,110,85,73,32,20320,22909,32,55357,56898` | `150-notepad-external.png` |
| Notepad Ctrl+A、Ctrl+C | 选区为全部 22 码元 | 无 |

| Ctrl+Z | text=[ZenUI clipboard]，selected=[ZenUI clipboard] | `150-zenui-paste-undo.png` |

## 边界

- 只在单屏 150% 运行；100%、混合 DPI 与其它应用不在本工单证据范围。
- 系统剪贴板原始字节没有直接读取；应用写入由 Notepad 粘贴结果观察，Notepad 写入由
  应用粘贴后的 UIA 文本观察。
- 隐藏测试使用内存 provider：189 个 `zenui-windows` 库测试包含 9 个新增宿主测试与
  2 个剪贴板模块测试，不触碰系统剪贴板；AltGr、失败与跨窗口路径只由隐藏测试覆盖。
- Notepad 恢复的其它标签页含本地文件；本目录截图不含其标题或内容。采集结束后 Notepad
  与其它标签页保持原状，证据文本仍在系统剪贴板。
