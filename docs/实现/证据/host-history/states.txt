# #204/#205 文本撤销/重做可见证据

日期: 2026-11-24
基线: main 620d60b（含 #204 的宿主映射），#205 的连续输入合并
示例: crates/windows/examples/todo_host.rs（ZenUI Todo），debug 构建
窗口: 单屏 2560×1600，150%（144 DPI）；外框 1372×1106 物理像素，位于屏幕 (48,48)，
      客户区 1350×1050 物理像素；窗口物理原点与 `PrintWindow` 输出原点相同。

## 采集方式

- 窗口图来自 `PrintWindow(PW_RENDERFULLCONTENT)`，整窗读取；右/下的黑色条是采集产物。
- 点击草稿输入与按键由仓库外的 PowerShell 脚本用 `mouse_event` / `keybd_event` 注入，
  是真实键盘消息队列；窗口在操作前用 `SetForegroundWindow` 置前，每次脚本输出都确认
  `fg` 与目标 HWND 相同。
- 文本值由仓库外的 UIA `TextPattern` 客户端读取 `DocumentRange.GetText(-1)`，把不可见
  的尾随空格也记录为 UTF-16 码元。
- 输入法当时为微软拼音。中文模式下键入字母形成 preedit（下划线），此时 Ctrl+Z 不改变
  preedit 或值，组合优先由 IME/宿主组合路径消费；正式采集前用一次真实 Shift 按键切到
  英文模式，随后键入的字母与空格是已提交编辑，截图中无 preedit 下划线。

## 操作读数

| 步骤 | UIA 文本（码元） | 证据 |
| --- | --- | --- |
| 初始，草稿输入聚焦且为空 | `""`（长度 0） | `150-initial.png` |
| 键入 `ab cd` | `ab cd`（`97,98,32,99,100`） | `150-typed.png` |
| Ctrl+Z（撤销第二个词） | `ab `（`97,98,32`，长度 3） | `150-undo.png` |
| Ctrl+Z（撤销第一个 run） | `""`（长度 0） | `150-undo-run.png` |
| Ctrl+Y（重做第一个 run） | `ab `（`97,98,32`，长度 3） | `150-redo.png` |
| 键入 `x`（清空 redo） | `ab x`（`97,98,32,120`） | `150-redo-cleared-before.png` |
| Ctrl+Y（redo 已清空） | `ab x` 不变（`97,98,32,120`） | `150-redo-cleared-after.png` |

空格在截图中不可见，UIA 读数证明第一次撤销后尾随空格仍在；两次清空 redo 后的读数都是
`ab x`。最后两张图的 caret 闪烁相位可能不同，文本与码元相同。

## 边界

- 只在单屏 150% 运行；键位与合并策略不依赖 DPI，没有重复 100% 或混合 DPI。
- 没有单独记录人工逐项按键或视觉复核；截图、`fg`/HWND 与 UIA 读数来自自动注入。
- 没有在可见运行中覆盖两个输入的历史隔离、Backspace/Delete 撤销、中文组合提交或 64 字符
  上界；这些由隐藏测试与 #206 的验收页补充。
