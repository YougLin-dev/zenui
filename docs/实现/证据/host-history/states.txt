# #204/#205/#206 文本编辑历史可见证据

日期: 2026-11-24
基线: main ae7cd74（#204 宿主映射 + #205 连续输入合并）
示例: crates/windows/examples/todo_host.rs（ZenUI Todo / ZenUI Details），debug 构建

## 环境与采集

- 单屏 2560×1600，150%（144 DPI）。
- 主窗口 `ZenUI Todo`：外框 1372×1106 物理像素，位于屏幕 (48,48)，客户区 1350×1050。
- 详情窗口 `ZenUI Details`：外框 802×686 物理像素，位于屏幕 (48,48)，客户区 780×630。
- 窗口图来自 `PrintWindow(PW_RENDERFULLCONTENT)`，整窗读取；右/下的黑色条是采集产物。
- 点击与按键由仓库外的 PowerShell 脚本用 `mouse_event` / `keybd_event` 注入，是真实键盘消息队列；
  每次操作前用 `SetForegroundWindow` 置前并确认 `fg` 与目标 HWND 相同。
- 文本值与选择由仓库外的 UIA `TextPattern` 客户端读取 `DocumentRange.GetText(-1)` 与
  `GetSelection`；不可见的尾随空格也记录为 UTF-16 码元。
- 输入法为微软拼音。英文场景前用一次真实 Shift 切到英文模式；中文场景直接键入拼音，
  preedit 由应用绘制下划线。候选提交后系统 IME 可能继续在应用上绘制组合下划线；UIA
  已提交值与随后 Ctrl+Z 的行为表明它不是运行时 composition，下划线何时消失由 IME
  决定，截图保留所见。中文提交截图中的下划线是系统 IME 的残留组合指示。

## 选择替换

键入 `abcd`，Ctrl+A 全选，再键入 `y`；Ctrl+Z 恢复 `abcd` 与撤销前的选择。

- 替换后：`text=[y]`，selection `selected=[]`；证据 `150-selection-replaced.png`。
- Ctrl+Z 后：`text=[abcd]`，selection `selected=[abcd]`；证据 `150-selection-restored.png`。

## Backspace 与 Delete

- 键入 `abcd`，End，Backspace：`text=[abc]`；证据 `150-backspace.png`。
- Ctrl+Z：`text=[abcd]`；证据 `150-backspace-undo.png`。
- Home，Delete：`text=[bcd]`；证据 `150-delete.png`。
- Ctrl+Z：`text=[abcd]`；证据 `150-delete-undo.png`。

## 中文组合提交

- 键入 `nihao`：preedit `nǐhao`，`TextPattern` 已提交值为空；证据 `150-ime-preedit.png`。
- Space 选中候选：已提交 `你好`（`20320,22909`）；系统 IME 的组合下划线可能仍在，
  UIA 与 Ctrl+Z 表明它不是运行时 composition；证据 `150-ime-committed.png`。
- Ctrl+Z：`""`；证据 `150-ime-undo.png`。

## 两个输入 / 两个窗口

- 主窗口草稿保留 `main`（`109,97,105,110`），避免系统 IME 下划线混入两窗口读数。
- 打开 `ZenUI Details`，在 `Details note` 键入 `note`：`text=[note]`；证据 `150-details-typed.png`。
- 在详情窗口 Ctrl+Z：`Details note` 为 `""`；证据 `150-details-undo.png`。
- 主窗口读数仍为 `main`；证据 `150-two-windows-main.png`。撤销详情输入不写主窗口模型。

## 空栈

新建的可见运行中，草稿输入聚焦且为空时按 Ctrl+Z 与 Ctrl+Y：值保持 `""`，caret 与焦点
不变，没有 `on:input`。证据 `150-empty-undo.png` 与 `150-empty-redo.png`。

- 2026-11-24 的 workspace 串行 810 个测试通过。
- 隐藏/CI 是部分证据；可见运行只覆盖本文件列出的场景，没有逐项人工视觉复核。

## 边界

- 只在单屏 150% 运行；键位、合并策略与历史语义不依赖 DPI，没有重复 100% 或混合 DPI。
- 两个输入/窗口的可见隔离只覆盖主窗口草稿与详情窗口 note；更多窗口与隐藏后历史由隐藏测试覆盖。
- 中文提交截图中的下划线是系统 IME 的残留组合指示，不是 ZenUI 的运行时 preedit；不以该下划线
  何时消失判断组合或历史状态。
- 截图只含示例 Todo 窗口与操作读数，不含用户文档或个人数据；临时脚本与 UIA 客户端在仓库外。
