# #204 文本撤销/重做可见证据

日期: 2026-11-24
示例: crates/windows/examples/todo_host.rs（ZenUI Todo），debug 构建
窗口: 单屏 2560×1600，150%（144 DPI）；外框 1372×1106 物理像素，位于屏幕 (48,48)，
      客户区 1350×1050 物理像素；窗口物理原点与 `PrintWindow` 输出原点相同。

## 采集方式

- 窗口图来自 `PrintWindow(PW_RENDERFULLCONTENT)`，整窗读取；右/下的黑色条是采集产物。
- 点击草稿输入与按键由仓库外的 PowerShell 脚本用 `mouse_event` / `keybd_event` 注入，
  是真实键盘消息队列；窗口在操作前用 `SetForegroundWindow` 置前，每次脚本输出都确认
  `fg` 与目标 HWND 相同。
- 输入法当时为微软拼音。中文模式下键入字母形成 preedit（下划线），此时 Ctrl+Z 不改变
  preedit 或值，组合优先由 IME/宿主组合路径消费；正式采集前用一次真实 Shift 按键切到
  英文模式，随后键入的字母是已提交编辑，截图中无 preedit 下划线。

## 操作读数

| 步骤 | 输入值 | 证据 |
| --- | --- | --- |
| 初始，草稿输入聚焦且为空 | `""` | `150-initial.png` |
| 键入 `abc`（三个单字符编辑） | `abc`，caret 在末尾 | `150-typed.png` |
| Ctrl+Z（撤销最近一次编辑） | `ab`，caret 在末尾 | `150-undo.png` |
| Ctrl+Y（重做） | `abc`，caret 在末尾 | `150-redo.png` |
| 再次 Ctrl+Z 后键入 `d` | `abd`，caret 在末尾 | `150-redo-cleared-before.png` |
| Ctrl+Y（redo 已被新编辑清空） | `abd` 不变 | `150-redo-cleared-after.png` |

最后两张图字节相同：新编辑清空 redo 栈后，Ctrl+Y 不派发 `on:input`，值、caret 与焦点
都不变。本切片每个单字符插入是一条历史；把连续输入合并为词级撤销由 #205 处理。

## 隐藏测试补充

- `ctrl_z_undoes_and_ctrl_y_redoes_value_caret_and_selection_once`：先设置 selection、
  用字符替换选区，再按 Ctrl+Z/Y；断言值、caret、anchor、归一化 selection 与每次恰好一次
  `on:input`。
- `typing_after_undo_clears_the_redo_stack`：撤销后键入新字符，再 Ctrl+Y 不派发。
- `undo_and_redo_without_a_focused_input_are_consumed_no_ops`：没有焦点时不派发、不移动焦点。
- `undo_and_redo_during_composition_are_consumed_no_ops`：组合保持，preedit 不被编辑。
- `undo_and_redo_after_the_focused_input_is_disabled_are_consumed_no_ops`：输入被禁用后
  按键不派发、不移动焦点。

隐藏宿主测试只断言 presentation snapshot，不替代可见运行；菜单快捷键、剪贴板与组合提交的
可见交互仍由各自工单覆盖。

## 边界

- 只在单屏 150% 运行；这次键位映射不依赖 DPI，没有重复 100% 或混合 DPI。
- 没有单独记录人工逐项按键或视觉复核；截图与 `fg`/HWND 读数来自自动注入。
- 没有在可见运行中覆盖两个输入的历史隔离、Backspace/Delete 撤销或中文组合提交；这些由
  隐藏测试与 #206 的验收页补充。
