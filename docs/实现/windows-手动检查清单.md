## 构建与启动

- [ ] 从 `templates/minimal-app` 复制到仓库外，只改两个 path 依赖，使用公开文档构建成功。
- [ ] release exe 双击启动，无控制台窗口；窗口标题、初始尺寸正确。
- [ ] 关闭最后一个窗口后进程退出（默认会话策略）。

证据：构建日志、exe 路径、启动截图。

## Phase 0：基本闭环与空闲

- [ ] 输入、添加、勾选、过滤、删除 Todo 各一次；焦点与 caret 跟随操作。
- [ ] 空闲且未聚焦 15 秒：任务管理器 CPU 接近 0，窗口不持续重绘。
- [ ] 聚焦编辑器空闲：只有 caret 闪烁，CPU 不持续升高。
- [ ] 30 分钟脚本长跑：10k 列表滚动、键入、隐藏/显示、任务完成；工作集、句柄与场景构建次数有界。
- [ ] 尝试 Win+Ctrl+Shift+B 或强制 GPU 负载；记录是否出现设备丢失。没有观察到恢复时，不记录为通过。

证据：15 秒 CPU 采样、长跑读数、事件查看器截图。

## Phase 2 / 3：输入、IME、UIA

- [ ] 微软拼音组合：输入 `nihao`，候选确认后文本正确；Esc 取消组合不插入文本。
- [ ] 组合期间 Enter 确认候选，不提交表单；普通 Enter 只提交一次。
- [ ] 组合中切换焦点或外部替换草稿：preedit 被取消，不残留字符。
- [ ] hover、按下、释放、禁用按钮：视觉与命中一致；按在按钮上移出再释放不触发。
- [ ] 100% 与 150% 下分别重复一次输入、滚动、点击与焦点显露。
- [ ] Inspect 打开 Todo 窗口：根是 Window，列表/按钮/复选/输入角色与名称正确；100%/150% 边界与场景一致。
- [ ] Narrator 朗读 Todo：按钮名称、复选状态、输入值与 selection 正确；不重复朗读。
- [ ] 菜单栏、快捷键、右键上下文菜单、托盘菜单各触发一次；禁用项不运行。
- [ ] 从资源管理器拖入单个文件、多个文件、Unicode 路径与文件夹；模态对话框/关闭确认期间拖放被拒绝。
- [ ] 多窗口：显示/隐藏/重开/关闭确认；父窗口禁用、焦点恢复；窗口间模型共享。
- [ ] 高对比度开启：语义颜色与内建控件改用系统颜色，显式字面颜色不变；关闭后恢复。
- [ ] 文本大小 100% → 225%：文本、行高、caret、命中与滚动范围放大；固定 `px` 不放大；树 revision 与编辑状态保持。

证据：每个条目的截图或录屏路径、Inspect 树导出、Narrator 记录。

## Phase 4：滚动、窗口化 For、damage

- [ ] 100% 与 150%：滚轮、PageUp/PageDown、Home/End、滚动条 thumb 拖动与轨道翻页；边界夹取不回吞。
- [ ] 10k 行窗口化 For：滚动跨行时行身份、焦点、caret、selection 与组合保持；只有一行 grace 内的聚焦行保留焦点。
- [ ] 行内滚动不重建快照；跨行滚动只发生一次结构更新（可通过宿主计数或调试读数确认）。
- [ ] 编辑窗口内行、过滤与重排：编辑状态不串行，旧 NodeId 不命中新行。
- [ ] UIA 事件：焦点、ToggleState、Value 与结构变化各投递一次；后台窗口不抢前台焦点事件。
- [ ] 主题切换：所有窗口重绘，未使用 `dark:` 的窗口也可复用布局；焦点/caret/selection 保留。
- [ ] 滚动、裁剪与 resize 后无幽灵像素或错位命中；damage 未实现局部绘制时记录为“完整重绘”，不记为通过局部 damage。

证据：截图/录屏、Inspect 事件记录、滚动读数。

## Phase 5：发布与外部使用

- [ ] release 包复制到另一个目录后启动；资产缺失时显示明确错误并以非零码退出。
- [ ] 外部开发者按公开文档完成复制、构建、运行、修改与诊断；记录摩擦并转为 issue。
- [ ] 启动、退出、再次启动；更新路径未实现时明确记录“未覆盖”，不能写为已交付。

证据：发布目录、启动截图、外部试用记录。

## 记录规则

- 通过项必须附实际读数或证据路径；只有“看起来正常”不构成验收。
- 未执行、被跳过或环境不满足的项写“待执行/未覆盖”，并说明原因。
- 任何 headless、renderer 或隐藏 HWND 结果只作为部分证据，不升级本清单结论。
- 完成后把每项结果同步到 [可见验收矩阵](stage-three-可见验收矩阵.md) 的对应 Phase 行。
