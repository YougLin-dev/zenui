# 渲染与平台

## 原生控件树与派生绘制

ZenUI 保留原生控件树作为界面身份和交互状态的归宿。模型与派生值的变化在这里形成 typed patch，布局、文本测量、绘制与命中再消费已提交的描述。

这里不是一棵需要随每次字段更新重建的虚拟节点树。布局 cache、文本 shaping cache 和 retained paint record 是派生产物，不应反过来独立修改界面或 Store。

## 2D 主干

ZenUI 的 2D 路线使用适合原生布局、丰富文本与 GPU 绘制的组件：布局与文本各自负责计算，样式源提供 typed declaration，绘制层接收已提交的几何与显示内容。

针对这些模块的实际依赖和版本以各工作区 Cargo manifest 为准。当前 `crates/core` 是纯标准库 headless 实现，不等同于完整的渲染后端；`examples/native_poc` 与 `examples/desktop_poc` 分别验证局部文本、布局和离屏 GPU 机制。

窗口大小、DPI、字体、软件 fallback、driver 与 GPU capabilities 都会影响绘制表现。不假定一个离屏 readback 就能代表真实窗口、不同 DPI 和不同 driver 的最终视觉效果。

## Renderer 拥有的 transient

frame time、动画插值、滚动瞬时偏移和 GPU 资源分配由 renderer 管理。tick 只在需要工作的阶段保持活跃，空闲窗口可以停止呈现。

`Signal` / `Memo` 依然可以提供颜色、业务进度或动画目标。它们是稳定输入，而不是每帧回写业务状态的 channel。布局中发生的测量和绘制异常不应反向发起第二套模型写流程。

隐藏窗口可以保留它的 Owner 和控件状态，但应停止输入、语义动作和 presentation；窗口关闭后，其 renderer lease、surface 与任务交付失效。

## Content handle 与 native attachment

`CanvasContent`、`TextureSource`、`SceneHandle` 等 Copy handle 表示可共享的内容或资源描述。它们可以出现在 `Show` 的两个分支：

```rust
<Show when={streaming} fallback={move || view! {
    <canvas content={chart} />
}}>
    <canvas content={chart} ticker={tick} />
</Show>
```

共享 content 不等于复用 native attachment。每个 mounted leaf 与自己的 window、activation 和 device generation 对应；不同 branch 更替或重新创建控件时，要释放旧 lease，再创建或绑定新 lease。

资源 Copy 只回答 Rust 捕获的便利性，不能证明 GPU attachment 一直有效，也不能跨窗口随意复用设备本地对象。

## 图像、外部纹理与 3D

图像接口显式说明尺寸、格式、颜色空间和 alpha 约定。不能把一处不同 alpha premultiplication 假设的像素缓冲直接当成另一种纹理。

3D 作为布局中的内容叶节点接入，有独立的离屏颜色与深度，再融入 2D 绘制结果。它不是第二套界面树，也不承诺浏览器 scene graph、AR 或游戏引擎功能。

资源加载可以通过 worker 产生 Send 数据与资源 generation，能在 UI 激活状态确认后发布。迟到帧、旧 device 和已卸载 scene 的结局是资源取消或替换，不需要修改模型。

## 宿主能力

Windows、macOS、Linux 的窗口、输入法、菜单、托盘、对话框和读屏接口并不完全一样。ZenUI 为共同语义提供统一入口，把能力差异表达为明确的支持与否，而不是静默选择不同的工作流。

例如 dialog anchor 有效与任务 job 仍存活是两件独立的事；不同平台可以选择不同的 picker 取消策略，但不能让迟到的文件选择悄悄附着到新窗口。

## 平台验证的对象

局部原型能验证对应的有界机制：

- 宏原型的 parser、class lowering 和事件 laziness；
- headless core 的句柄、Owner、查询和事务；
- 指定尺寸、格式、字体和 GPU adapter 的离屏绘制。

真实窗口需要另行确认输入提交、IME、读屏动作、DPI、最小化隐藏和 native teardown。不能把某个辅助技术的视觉标记或某个 headless 软件渲染结果当作平台发布承诺。
